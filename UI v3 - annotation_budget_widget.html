How much data do I need to annotate?

Aligning a judge means checking how often it agrees with human judgments on a given criterion, then correcting its scores for the errors it makes. This calculator sizes that effort: it returns how many emails a human has to label before the judge's corrected score is precise enough to decide whether the business target is met.

  • Annotating more emails does not improve the judge's performance. It reduces the uncertainty around the estimated score, resulting in a narrower confidence interval.
  • The annotated emails should be representative of the same population as the emails evaluated by the judge.
  • The result is an estimate based on the current calibration data; its precision depends on the number of items already annotated. As more items are annotated, update the calculator with the current number of emails labelled MET and NOT MET, as well as the judge agreement measured on this updated calibration set.
  • All results are calculated using a 95% confidence level.
